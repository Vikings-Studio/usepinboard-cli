# Governance

Pinboard CLI is currently maintainer-led.

Maintainers set product scope, merge changes, cut releases, respond to security reports, and may appoint additional maintainers based on sustained, trusted contributions.

## Decision principles

1. Protect local privacy and cross-user trust boundaries.
2. Prefer provider-neutral standards and documented integration surfaces.
3. Do not claim unsupported provider capabilities.
4. Keep the Personal package useful without cloud access.
5. Validate cross-user demand before expanding platform scope.

Material protocol, persistence, identity, networking, telemetry, or security changes require an architecture decision record or equivalent design issue before implementation.

The project may reject changes that are technically sound but expand into orchestration, task allocation, issue tracking, or fleet management.
